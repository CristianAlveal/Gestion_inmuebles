Nuestro sitio web

Propiedades

Los usuarios podrán revisar las viviendas disponibles para arriendo y conocer sus principales características.

Base de datos

La información de las propiedades será almacenada y organizada mediante una base de datos.

Fácil búsqueda

Los usuarios podrán consultar las viviendas disponibles de manera sencilla y rápida.

Nuestro objetivo

Crear una plataforma web que permita administrar información de inmuebles y facilitar a los usuarios la búsqueda de viviendas disponibles para arriendo.

De esta manera, Casas en Arriendo busca entregar una experiencia sencilla, ordenada y accesible para quienes necesitan encontrar una vivienda.

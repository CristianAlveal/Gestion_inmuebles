Acerca de nosotros

Casas en Arriendo es una empresa dedicada al arriendo de inmuebles.

Nuestro objetivo es facilitar a los usuarios la búsqueda y revisión de viviendas disponibles para el arriendo, entregando información clara y organizada sobre las propiedades.

Para lograrlo, la empresa requiere un sitio web que permita administrar y mostrar información relacionada con las viviendas disponibles, facilitando el acceso de los usuarios a las propiedades que se encuentran disponibles para arrendar.

El sistema también contempla el diseño de una base de datos que permita almacenar y organizar toda la información necesaria para administrar las propiedades y sus características.
